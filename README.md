# 📿 Luxury Pearl Tasbih - Progressive Web App

Aplikasi tasbih digital yang elegan dengan desain mewah untuk membantu Anda dalam zikir dan doa islami.

## Fitur Utama

✨ **Fitur-Fitur:**
- 📿 5 Jenis Zikir: Tasbih, Tahmid, Takbir, Selawat, Istighfar
- 🎨 7 Pilihan Warna Mutiara: Putih, Pink, Biru, Hijau, Emas, Hitam, Merah
- 🔄 Mode Otomatis (Auto Mode) dengan kontrol Pause/Resume
- 🔊 Efek Suara yang Menyenangkan
- 📱 Instalasi sebagai Aplikasi (PWA)
- 🌐 Berfungsi Offline
- ⚡ Desain Responsif untuk Semua Perangkat

## Cara Menggunakan

### Online
1. Buka aplikasi di browser Anda
2. Klik tombol **Pasang Aplikasi** (jika tersedia)
3. Mulai gunakan!

### Sebagai Aplikasi
1. Buka di browser mobile atau desktop
2. Klik tombol **Pasang Aplikasi**
3. Aplikasi akan ditambahkan ke layar utama/aplikasi Anda
4. Buka kapan saja, bahkan saat offline

## Kontrol

- **📿 Kira**: Tambah hitungan satu per satu atau klik mutiara
- **▶ Auto**: Mulai mode otomatis (tekan lagi untuk pause)
- **↻ Reset**: Reset hitungan ke nol
- **Warna**: Ubah warna mutiara sesuai preferensi Anda

## Target Hitungan

- 📿 Tasbih: 33 kali
- 🤲 Tahmid: 33 kali
- 🕋 Takbir: 33 kali
- ❤️ Selawat: 100 kali
- 🤍 Istighfar: 1000 kali

## Teknologi

- HTML5
- CSS3 (Gradient, Animations)
- Vanilla JavaScript
- Service Worker (Offline Support)
- Web App Manifest (Installable)
- Web Audio API (Sound Effects)

## Instalasi Lokal

```bash
git clone https://github.com/marinamdte-wq/tasbih-pwa.git
cd tasbih-pwa

# Gunakan server lokal (contoh dengan Python):
python -m http.server 8000

# Atau dengan Node.js (http-server):
npx http-server
```

Kemudian buka `http://localhost:8000` di browser Anda.
